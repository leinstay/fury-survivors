# План запуска демки

Итог брейншторма. Основная сессия (Opus) читает этот файл, `CLAUDE.md` и `VISION.md` и ведёт работу по этапам.

## Решения

| Вопрос | Решение |
|---|---|
| Движок | Phaser 3.90.0, файлом в `vendor/`, ES-модули без сборки. npm только для dev-инструментов (Playwright, sharp) |
| Разрешение | 640×360, `pixelArt: true`, `roundPixels: true`, Scale FIT, целочисленное масштабирование где возможно |
| Рост персонажей | гуманоиды 48 px в кадре 64×64, опора по центру у ног. Летучая мышь ~16 px, слайм ~24–40 px, босс ~96 px в кадре 128×128 |
| Ракурс | все в три четверти вправо, влево `flipX`. Вверх/вниз нет |
| Анимация | 3 сгенерированные позы (стойка, шаг А, шаг Б) + процедурно: покачивание, сжатие, наклон, белая вспышка, отлёт, смерть-облачко. Если позы шага не совпадают: ходьба только процедурная |
| Элитные | перекраска палитры + контур, ×размер 1.25, лучший дроп |
| Этап | лес, 10 минут, на 10:00 босс, победа после босса |
| Ориентация | только горизонтальная, на портрете экран «поверни телефон» |
| Магазин, монеты, мета-прогрессия | нет в демке |
| Геймпад | да: стик/крестовина, A выбор, B назад, Start пауза |
| Звук | эффекты jsfxr → wav (`tools/make-sfx.mjs`), UI-клики Kenney CC0 при необходимости, музыка CC0 с OpenGameArt. Источники в `CREDITS.md` |
| Шрифт | пиксельный OFL-шрифт (например Pixelify Sans), лицензия в `CREDITS.md` |
| Репозиторий | `leinstay/fury-survivors`, публичный, Pages из `main` (корень) |
| Бюджет картинок | $5 на ключе, жёсткий стоп скрипта на $4.50 |

## Бюджет генерации ($5)

1. Первый запрос: проверить точный id модели и цену в `GET /api/v1/models` OpenRouter, сделать 1 картинку (героиня), записать реальную цену в `tools/gen-ledger.json`.
2. Экономия: **одна картинка = лист из 3 поз** (стойка, шаг А, шаг Б) в ряд на пурпурном фоне. Это и дешевле, и консистентнее.
3. Референсы в запрос: `references/main.png` (техника рисовки) + готовый лист героини (для врагов, чтобы держать стиль).
4. Генерирует только один процесс, последовательно. Перегенерация максимум 1 раз на позицию, дальше чинить скриптом или оставить процедурную анимацию.

Очерёдность (по важности, ~14 картинок + запас на ретраи):
1. Героиня-рыцарша (рыжие волосы, доспех с открытыми бёдрами/животом, меч)
2. Кошкодевочка, 3. Слайм-девочка, 4. Летучая мышь, 5. Призрак, 6. Лисодевочка, 7. Суккуба
8. Босс: королева-дриада (крупная)
9. Лист окружения леса: трава (тайлы), деревья, камни, цветы, кусты, бочка, фонарь
10. Лист предметов: кристаллы опыта 3 размеров, еда, магнит, сундук, монета
11. Лист иконок оружия и пассивок (16×16 или 24×24, сетка)
12. Лист снарядов/эффектов оружия
13. Портрет героини для HUD и меню
14. Арт для главного меню (по остатку бюджета)

Промпты: описываем только наряд и фигуру, без sexy/fanservice/seductive/busty (см. VISION.md).

## Конвейер чистки (`tools/clean-sprite.mjs`, sharp)

1. Вырезать хромакей (пурпурный) с допуском, убрать ореол.
2. Найти позы (связные области), разрезать лист на кадры.
3. Уменьшить каждую до целевого роста nearest/majority-сэмплингом.
4. Квантовать в `tools/palette.json` (снять с main.png и расширить до ~32 цветов).
5. Удалить одиночные пиксели, нарисовать тёмную обводку 1 px.
6. Положить в стандартный кадр, выровнять опору по ногам, собрать strip-PNG.
7. `tools/contact-sheet.mjs` собирает превью ×4 для проверки пользователем.

## Контент демки

**Оружие** (behavior в скобках):
- Blade Arc (melee_arc): стартовое у героини
- Throwing Daggers (projectile)
- Guardian Shields (orbit)
- Holy Ground (aura)
- War Axe (boomerang)
- Storm Chain (chain)
- Firebomb (area_drop)

По 7 уровней, баланс по мотивам вики VS/HoloCure.

**Пассивки:** Max HP, Attack, Speed, Crit, Pickup Radius, Haste, Luck, Armor, Regen.

**Супероружие (2 для демки):** Blade Arc max + Guardian Shields max = Aegis Storm. Throwing Daggers max + Storm Chain max = Thunder Knives. Выпадает из сундука элиты/босса, если обе части на максимуме.

**Враги:** bat (swarm), slime (chase, медленный, много HP), catgirl (chase, быстрая), ghost (phase, кольцом), foxgirl (dash), succubus (ranged). Элитные версии любых через data. Босс: королева-дриада (рывки + призыв).

**Таймлайн леса (черновик, правится в `src/data/stages/forest.js`):**
0:00 летучие мыши · 1:00 слаймы · 2:00 кошкодевочки · 3:00 кольцо призраков · 4:00 элита + сундук · 5:00 лисодевочки · 6:30 суккубы · 7:30 элита · 8:30 общая волна · 10:00 босс.

**Механики:** автоатака, опыт + магнит + слияние кристаллов, карточки уровня (4 шт., Reroll / Skip / Banish), 6 слотов оружия + 6 пассивок, статы (HP, ATK, SPD, CRT, Pickup, Haste, Luck, Armor), отбрасывание, неуязвимость после удара, элиты, сундуки, разрушаемые объекты с едой/магнитом, еда лечит, хитстоп, тряска, числа урона, вспышка при уровне, перенос отставших врагов вперёд, лимит врагов.

**Экраны:** Menu (Play, Settings: громкость музыки/звуков, Quit-заглушка), Game + HUD, LevelUp, Pause (продолжить, громкость, выйти в меню, текущий билд), GameOver/Victory (время, уровень, убийства, урон по оружию, Retry, Menu).

## Этапы

Основная сессия после каждого этапа: прогоняет тесты, коммитит, пушит, проверяет расход (`get_usage`), сообщает при 75%.

**Этап 0. Каркас (основная сессия, ~10 мин)**
- `git init`, `.gitignore` уже есть, `gh repo create leinstay/fury-survivors --public`, включить Pages.
- Скачать Phaser 3.90.0 в `vendor/`, `index.html`, `src/main.js` с пустыми сценами, `package.json` (scripts: test, smoke, serve).
- Пустые файлы `src/data/*` с контрактами (формат записей) и `assets/sprites/manifest.js`.
- `tools/placeholders.mjs` → заглушки. Первый деплой: чёрный экран с надписью грузится по ссылке.

**Этап 1. Играбельная версия на заглушках (параллельно, цель: 30 мин от старта)**
- Агент A: `src/core/*`, `src/behaviors/*`, `src/data/*`, `tests/unit`, `tests/balance`.
- Агент B: `src/scenes/*`, `src/ui/*`, `src/i18n/*`, `src/render/*` (без fx), smoke-тест.
- Основная сессия: `tools/gen-sprite.mjs`, `tools/clean-sprite.mjs`, тестовая генерация героини, показ пользователю.
- Итог: деплой, ссылка пользователю.

**Этап 2. Сочность и ассеты**
- Агент A: `src/render/fx.js`, `src/render/anim.js`, хитстоп, тряска, числа урона, частицы.
- Агент B: `tools/make-sfx.mjs`, `src/audio/*`, музыка, джойстик, геймпад, экран поворота.
- Основная сессия: генерация врагов по очереди, чистка, contact sheet пользователю, подмена файлов.

**Этап 3. Глубина**
- Агент A: элиты, сундуки, комбо, разрушаемые объекты, босс (core + data).
- Агент B: экраны GameOver/Victory со статистикой, пауза с билдом, полировка UI.
- Основная сессия: окружение и иконки.

**Этап 4. Финал**
- Агент: `docs/HOW-TO-ADD.md` (оружие, пассивка, герой, враг, элита, босс, карта, объект, волна/событие, комбо), `docs/ARCHITECTURE.md`, `docs/ASSETS.md`.
- Баланс-прогон, проверка fps на 400 врагах, финальный деплой.

## Тесты

- `tests/unit`: сетка коллизий, подсчёт статов, генерация карточек, валидация данных (у каждого оружия есть behavior, иконка, корректные уровни; у врагов есть спрайт в manifest; комбо ссылаются на существующее).
- `tests/balance`: бот на `core/sim` (жадный выбор улучшений, кайт от врагов) играет 10 мин игрового времени за секунды с фиксированным сидом. Проверки: уровень к 5:00 в диапазоне, время до 10 уровня, бот без апгрейдов умирает раньше 4 мин, бот с апгрейдами доживает до босса, число врагов не выше лимита.
- `tests/smoke`: Playwright открывает страницу, Start, 30 с случайного движения, `__game.debug()` без ошибок, fps > 50, консоль чистая. Скриншот 320×180 только с флагом `--shot`.

## Безопасность

- `.secrets/` и `references/` в `.gitignore` с первого коммита.
- Pre-commit хук: отказ, если в индексе есть `sk-or-` или файлы из `.secrets/`.
- Ключ читает только `tools/gen-sprite.mjs` из файла; никакого ключа в `src/`.
