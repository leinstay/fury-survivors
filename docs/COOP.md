# Сетевой кооп: состояние и что дальше

Полная схема в `docs/ARCHITECTURE.md` («Сетевой кооп»), таблицы и правила в `docs/LEADERBOARD.md`. Здесь короткая сводка для продолжения работы.

## Сделано

- Симуляция на двоих (`src/core/sim.js`, числа в `src/data/coop.js`): общий опыт и уровень, карточки по очереди, сундук тому, кто подобрал, гроб вместо смерти (оживает по таймеру, быстрее рядом с напарником), игроки не расходятся дальше экрана, спавн ×1.4, HP врагов ×1.15, по 4 слота на игрока.
- Герои: мечница (Blade Arc) и магесса (Storm Chain, `HEROES.mage`). Выбор героя в соло (меню: Play → герой → сложность, последний выбор в настройке `hero`) и в лобби (каждый выбирает сам, сообщение `hero`, хост передаёт `heroes` в `start`). Одинаковые герои различаются голубой подкраской второго. Спрайт магессы: PixelLab по `assets/raw/mage.png`, в меню она слева отражённой, симметрично мечнице.
- Lockstep (`src/core/lockstep.js`): ввод с задержкой 4 тика, команды экранов, хеш состояния раз в секунду. Фиксированный шаг 60 Гц в `Game.js` (и в соло).
- Соединение (`src/services/net.js`): WebRTC DataChannel, offer/answer через Firestore `rooms/<код>`, STUN Google, без TURN.
- Лобби (`src/scenes/Lobby.js`), вид Co-op в меню, HUD с полоской напарника, итоги с парой ников, таблица коопа `fury_scores_coop` с полем `ip` и дедупом по IP, вкладки Solo / Co-op.
- Тесты: `tests/unit/coop.test.js`, `tests/unit/lockstep.test.js`, балансный бот на двоих (`players: 2`), `tests/smoke/coop.spec.js` (два окна, настоящий WebRTC, сигналинг через localStorage).

## Нужно руками

- Опубликовать `firestore.rules` в консоли Firebase (коллекции `rooms`, `fury_scores_coop`, поле `ip`). Без этого лобби не создаётся.
- Портрет магессы (`mage_portrait`, 48×48) пока заглушка, в игре он нигде не показывается.

## Известные ограничения

- Нет TURN: за симметричным NAT соединение не пройдёт (лобби скажет «Could not connect»).
- Рассинхрон только фиксируется (`__game.debug().desynced`), игра не чинит состояние. Chrome с Chrome сходится.
- Экран с содержимым сундука в коопе закрывается сам через 2.5 с, сим напарника не ждёт.
- Повтор забега в коопе только через новое лобби.
